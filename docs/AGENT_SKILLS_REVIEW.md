# Read-only Agent Skills Review Scope

Review discovery, parsing, progressive text reads, manager visibility, creator drafts,
and integration with the current vivi dependency. Automatic saving is disabled everywhere;
no writer, save dispatch, or save tool is exposed. Existing private-state exclusions remain.

Use ordinary functional fixtures only. Prior restricted assessments remain excluded and
must not be recreated or rerouted. Passing read/UI tests does not complete the earlier
security assessment or establish automatic-save acceptance. No live providers, real
credentials, user computer, physical UI, or executable skill scripts are needed.
